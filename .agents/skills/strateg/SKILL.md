# Начать или продолжить

1. `python tools/strateg.py status`.
2. Проекта нет или запрос новый → спроси запрос одной фразой, придумай короткий slug и создай проект:
   `python tools/strateg.py new <slug> --title "..." --request "дословный запрос"` → навык `strateg-brief`.
3. Проект есть → скажи человеку в 2–4 строках: этап, что сделано, что предлагаешь дальше, что требует внимания
   (строки «!» из status). Затем открой навык текущего этапа из таблицы в `AGENTS.md`.
4. В status есть «НЕЗАВЕРШЁННЫЕ действия» → сначала проверь их результат (файл появился? запись есть?),
   закрой `log done J-…` или `log fail J-… --error "..."`, и только потом продолжай. Не повторяй вслепую.
5. Несколько проектов → `python tools/strateg.py projects`, переключение `use <slug>`.

Правила работы — `AGENTS.md`. Методика — `knowledge/INDEX.md`.
