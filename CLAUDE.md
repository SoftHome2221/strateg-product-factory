## Дополнение для Claude Code

- Хуки (`.claude/settings.json`) сами подставляют состояние проекта в начале сеанса, проверяют источники и секреты,
  записывают в журнал веб-запросы и субагентов и считают расход токенов по транскрипту.
- Субагенты: `researcher` (быстрая модель), `critic` (сильная модель, отдельный контекст), `respondent` (модельный респондент).
- Навыки вызываются по имени: `/strateg`, `/strateg-brief`, … или подгружаются автоматически по описанию.
