# Анализ данных

Методика: `knowledge/data.md`, словарь показателей — `knowledge/metrics.md`.

## Шаги

1. Таблица должна быть в реестре: `ingest <файл>` (xlsx будет разложен на csv по листам).
2. `python tools/strateg.py data profile <csv>` — прочитай предупреждения. Проверь четыре вещи: определение показателя,
   единицы, период (полон ли последний), пропуски и дубли. Неясное определение — вопрос человеку или записанное допущение.
3. Выбери метод под вопрос:
   - остаются ли пользователи → `data retention <csv> --user <столбец> --date <столбец>`;
   - у кого проблема → `data groupby <csv> --by <признак> [--metric <столбец> --agg mean|sum|median]`;
   - отличаются ли группы → `data compare --a успехов/всего --b успехов/всего`.
   Нужен другой метод → короткий скрипт в `projects/<slug>/analysis/`, запуск, вывод сохранить рядом.
4. Каждый расчёт сохраняется как `analysis/A-00N-….md` с командой для повтора.
5. Прочитай результат критически: размер групп, интервал, смена состава, неполный период, связь ≠ причина.
6. Запиши результат сведением: `ev add --type fact --source S-<таблица> --loc "расчёт A-00N" --period "…" --claim "показатель, группа, период, размер"`.
   Причинные объяснения — гипотезами.
7. В текст переноси число вместе с оговоркой из расчёта.

## Не делай

- Не считай по превью таблицы и не оценивай «на глаз».
- Не сравнивай неполный период с полным.
- Не выдавай учебные или сгенерированные данные за сведения о реальном рынке.
