# Этап 3. Исследование и картина ситуации

Методика: `knowledge/research.md`, `knowledge/evidence.md`. Методы: `strateg-data`, `strateg-interviews`, `strateg-ux`.

## Шаги

1. **План.** Заполни `state/research_plan.md`: 4–7 вопросов; для каждого — какой ответ изменит решение, где искать,
   цена ответа. Запиши правило остановки. Покажи план человеку одной короткой таблицей (ответа не жди, если он не просил).
2. **Маршрут.** Для каждого вопроса: `route pick "..."`. Расчёты → скрипт; длинные источники и поиск → субагент
   `researcher`; интерфейсы → `strateg-ux`; причины поведения → `strateg-interviews`.
3. **Сведения.** По каждому вопросу извлеки утверждения и запиши:
   `ev add --type fact --source S-… --loc "…" --claim "…" --period "…" --conf … --q Q…`.
   Гипотезы — `--type hypothesis` с указанием, что их опровергнет (в `--note`).
   Субагенту `researcher` передавай: вопрос, id источников, формат ответа. Его находки проверь выборочно по тексту источника.
4. **Сопоставление.** Важное утверждение — два независимых источника или один первичный. Расхождения не сглаживай.
5. **Выводы.** Обобщения записывай `concl add --text "…" --based-on E-…,E-…`. Скрипт покажет силу оснований.
6. **Пробелы.** Нет ответа → строка в «Пробелы» плана: чего не знаем, почему, чем опасно, как закрыть.
7. Отмечай статус вопросов в плане по ходу работы. Остановись по правилу остановки.
8. **Картина.** `stage start research` создаёт `outputs/02-situation.md` из шаблона. Заполни: коротко; что известно;
   что предполагаем; где источники расходятся; чего не знаем; что это значит для решения.
9. `validate research`. Исправь ошибки.
10. **Развилка.** Покажи человеку «Коротко», 3–5 главных фактов, главные пробелы и спроси: достаточно или копать дальше
    (и что именно). `stage done research --human "..."`, затем `stage start options`.

## Готово, когда

- у каждого вопроса плана статус: закрыт (со сведениями) или пробел (с причиной);
- в картине каждое утверждение со ссылкой или пометкой; раздел «Чего мы не знаем» непустой;
- человек сказал «достаточно».

## Не делай

- Не исследуй то, что не меняет решение.
- Не записывай фактом оценку автора, своё обобщение или слова человека без данных.
- Не скрывай слабость данных уверенным тоном.
