# План исследования

СИНТЕТИКА. Проверка процесса на вымышленных входах, без выводов о реальном рынке.

| Вопрос | Как ответ меняет решение | Где искать / маршрут | Цена | Статус |
|---|---|---|---|---|
| Q1. Доказывают ли условные оплаты преимущество сегмента? | Не выбирать сегмент по неподтверждённому спросу | S-002, S-003, готовые A-001–A-004; скрипт | Без повторного расчёта | Закрыт для QA: [C-001] |
| Q2. Есть ли практическая причина начать с организаторов? | Доступный канал упрощает подготовку, не доказывая спрос | S-001, S-002; синтез | Короткое чтение | Условно: [C-002], гипотеза [E-015] |
| Q3. Какие обещания соответствуют продукту? | Убрать лишние обещания | S-001; сопоставление | Короткое чтение | Закрыт для сценария: [C-003] |
| Q4. Достаточно ли входов для запуска? | При неизвестной экономике — только подготовка | S-001, S-002; синтез | Реальные данные недоступны | Пробел: [C-004] |

Правило остановки: вопросы либо закрыты входами, либо оформлены как пробелы. Новые вымышленные материалы не докажут реальный спрос.

Пробелы: реальные причины покупки, удержание, затраты поддержки и экономика. До настоящего запуска нужны реальные обезличенные интервью с согласием, смета и отдельно разрешённый эксперимент. В этой задаче их нет [E-006], [E-009], [E-010].
