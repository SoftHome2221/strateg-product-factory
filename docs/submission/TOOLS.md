# Модели сервисы и инструменты

Названия ниже взяты из сохранённых журналов и протоколов. Список разделяет выполнение демонстрационной задачи,
разработку, сравнение и проверки. Это не список обязательных платных зависимостей для запуска.

| Модель или среда | Зачем использована | Где подтверждение |
|---|---|---|
| Claude Opus 5.5 (`claude-opus-5-5`) | основной анализ и критика исходного family-cloud | family-cloud/state/sessions.jsonl |
| Claude Haiku 5.5 (`claude-haiku-5-5`) | дополнительные задачи и исторический обычный чат | sessions.jsonl, benchmarks/README.md |
| Claude Sonnet 5.5 (`claude-sonnet-5-5`) | дополнительный сеанс family-cloud; отдельная принадлежность к демо не установлена | family-cloud/state/sessions.jsonl |
| Claude Fable 5.2 (`claude-fable-5-2`) | общий сеанс разработки и сборки demo-shield | demo-shield/state/sessions.jsonl |
| GPT `gpt-6.1-sol`, Codex | парное сравнение чата и агента, проверки и продолжение учебного процесса | benchmarks/codex-2026-11-14/protocol.json, workflow-check/ |
| Grok 4.7, Cursor | учебный процесс и живые пробы MCP и хуков | cursor-full-cycle/result.json, cursor-hook-fixes/result.json |
| Qwen2.5 7B, Ollama | исторический локальный обычный чат без поиска | benchmarks/README.md |
| `bge-m3`, Ollama | дополнительный локальный векторный поиск | README.md, docs/ARCHITECTURE.md |
| Jev / `typesafe/jev`, Electron Hub | внешний классификатор подзадач, пять живых запросов | README.md; tools/router_jev.py |
| AI/ML API | альтернативный интерфейс Jev; проверен локальной имитацией, не живым запросом | tests/selftest.py |
| DeepSeek Harness 0.2.2-rc.2 | проверены подстановка состояния, защита файлов, журнал и учёт времени через адаптер хуков | docs/CHECK-DEEPSEEK.md |
| Codex и Claude Code | разработка, исправления, работа с файлами и независимые ИИ-критики | журналы и протоколы; точная модель каждого редакторского шага не восстановлена |

`<synthetic>` и `codex-auto-review` в учёте не трактуются как отдельные подтверждённые модели стратегии.
Синтетические респонденты и ИИ-критики не являются реальными людьми или слепой человеческой оценкой.

| Инструмент или сервис | Назначение |
|---|---|
| Python 3.9+ и стандартная библиотека | CLI, JSON/JSONL, расчёты, загрузка публичных страниц, валидация, MCP по stdio |
| MCP `strateg` | статус, поиск, источники, сведения, выводы, проверка и сборка отчёта для внешних клиентов |
| Веб-поиск и просмотр страниц среды | сбор открытых материалов; URL и место в источнике сохраняются |
| Claude Code, Codex, Cursor, DeepSeek Harness | среда работы; конфигурация и степень проверки различаются |
| Дополнительные роли researcher, critic, respondent | извлечение сведений, независимая критика, синтетические собеседники |
| Ollama | необязательные локальные модели для поиска и исторического сравнения |
| FFmpeg и ffprobe | контрольная запись тестового окна, декодирование и извлечение кадров; не автоматическое понимание видео |
| Синтезатор речи | озвученный учебный отрывок; голос и версия в журнале не записаны; это не реальное интервью |
| pypdf, truststore либо certifi | необязательные чтение PDF и сертификаты HTTPS |
| Git, GitHub CLI и GitHub | версия конкурсного пакета и открытый доступ жюри |
| ReportLab, Pillow, Poppler, pypdf | сборка описания PDF и визуальная проверка страниц; только подготовка подачи |
| Средства просмотра изображений и управления окнами | просмотр макетов и кадров, проверка Cursor; не часть обязательного ядра |

Ключевые инструкции доступны целиком: `AGENTS.md`, `.claude/skills/*/SKILL.md`, `.claude/agents/*.md`,
`.agents/skills/`, `.codex/agents/`, `.cursor/rules/strateg.mdc`.
Ключи и личные настройки в репозиторий не включены.
